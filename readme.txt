CL Hotel Core Plugin for the CL Hotel Classified Listing Theme.

== Description ==

CL Hotel Core is a companion plugin for the CL Hotel WordPress theme by RadiusTheme. It provides additional functionality including Elementor widgets, demo content import, booking support, and other hotel listing features.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/cl-hotel-core` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. The plugin works automatically with the CL Hotel theme.
